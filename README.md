# LeadDesk Mini

LeadDesk Mini is a full-stack CRM application developed as part of the Digital Heroes assessment.

## Features

- Landing Page
- Lead Submission Form
- Admin Dashboard
- JWT Authentication
- Search & Filter
- Lead Status Management
- Delete Leads
- Responsive UI

## Tech Stack

Frontend:
- React
- Tailwind CSS
- Axios

Backend:
- Node.js
- Express.js
- Sequelize
- MySQL

Authentication:
- JWT
